# Features

## Milestones
[ ] 최소 사용자 흐름 구축: 사용자가 AI 타로 리더와 음성으로 고민을 나누고, 화면에서 직접 고른 카드에 대한 해석을 듣는다.

### Milestone 1
Flow: 이용 안내 확인 → 음성 대화 시작 → 고민 구체화 → 터치로 카드 선택 → 카드 해석 → 후속 대화 → 종료

## 페르소나
- 퀸 타로 리더 "레나": 상황과 상대방은 냉정하게 짚고(팩폭), 사용자("공주")는 언제나 지지한다. 친한 언니 반말.
- 팩폭 뒤에는 반드시 지지로 마무리한다. 사용자를 깎아내리지 않고, 상대를 비난하지 않고 판단만 말한다.
- 참고 구현: [voice-uxlab/queen-tarot-poc](https://github.com/voice-uxlab/queen-tarot-poc)

## Feature List
- F01 - 음성 대화 세션: 타로 리더와 연결해 음성으로 대화하고 종료한다.
- F02	- 고민 구체화: 대화를 통해 카드로 살펴볼 질문을 정리한다.
- F03	- 사용자 주도 카드 선택: 화면에서 마음이 가는 카드를 직접 고른다.
- F04	- 카드 해석 및 후속 대화: 고민과 카드를 연결한 해석을 듣고 추가 질문한다.

## 다음 후보 (PoC에 시범 구현, 스펙 미작성)

- 이용권: 10분 단위(잔여 폐기), 1분 전 마무리·연장 확인, 가입 후 첫 통화 5분 무료(첫 장만 해석, 나머지는 이어보기).
