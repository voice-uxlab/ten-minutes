# F03 - 사용자 주도 카드 선택

> 상태: 팀 검토용 초안. 구현 범위와 완료 조건을 검토하기 위한 문서입니다.

## 목적

사용자가 화면의 덱에서 자신의 카드 3장을 직접 선택하도록 한다. 선택 결과를 다음 대화 처리부에 정확히 전달한다.

## 책임 범위

- 소유: 확정 질문 수신, 카드 선택 안내, 덱 생성 및 표시, 터치 선택, 카드 공개, 결과 전달 및 전달 재시도.
- 경계: 질문 작성과 확인은 F02, 음성 송수신과 연결 오류는 F01, 전달된 카드의 해석 생성은 F04가 담당한다.
- 카드 결과가 수신부에 전달되면 이 기능의 처리가 완료된다. AI가 해석을 시작하는지는 F04에서 판정한다.

## 기본 흐름

1. 확정 질문을 받으면 카드 선택 UI를 활성화한다.
2. “1번부터 78번 중에 끌리는 숫자 세 개 골라줘, 화면에서 눌러도 돼”라고 안내하고 선택을 기다린다.
3. 사용자가 78장의 뒷면 카드에서 3장을 터치하거나 번호를 말한다.
4. 3장이 모이면 선택을 잠그고 셔플 연출 후 자리 3개에 뒷면으로 놓는다. 앞면은 F04가 해석 직전에 한 장씩 공개한다.
5. 확정 카드 결과를 발행하고 수신 확인을 받는다.

## 동작 규칙

| 항목 | 요구사항 |
|---|---|
| 덱 | 78장(메이저 22 + 마이너 56). 덱 생성 시 장마다 정/역방향을 무작위로 정한다. |
| 활성화 | 유효한 확정 질문이 없으면 카드를 선택할 수 없다. |
| 배정 | 덱 생성 시 무작위로 순서를 정하고 위치별 카드 정체를 고정한다. |
| 탐색 | 모바일 한 화면에 78장을 번호가 적힌 격자로 보여준다. |
| 음성 선택 | 번호를 말하면 같은 번호 자리의 카드를 고른다. 중복이나 1~78 밖의 번호는 다시 묻는다. |
| 확정 | 서로 다른 3장이 모이면 확정하고 나머지 선택을 잠근다. |
| 공개 | 고른 번호 자리에 미리 배정된 카드가 자리 1~3에 놓인다. 해석 직전에 한 장씩 앞면을 보여준다. |
| 중복 방지 | 연속 터치와 재시도로 추가 카드 또는 다른 결과를 만들지 않는다. |
| 상태 유지 | 재렌더링과 화면 크기 변경으로 순서 및 선택 결과를 바꾸지 않는다. |
| 기다림 | 선택 전 대리 추첨하거나 해석하지 않고 재촉하지 않는다. |

## 입력과 결과

- 입력: 확정 질문 및 버전, 카드 터치, 결과 전달 재시도, 질문 변경 요청.
- 결과: 덱/선택 UI, 선택 안내, 확정 카드 결과.
- 카드 결과에는 세션 및 질문 식별자, 질문 버전, 고유 선택 식별자, 카드 ID/이름/방향을 포함한다. 필드명과 내부 형식은 구현 시 정한다.
- 화면 카드와 전달 카드의 ID는 동일해야 한다.
- 수신 확인은 해석 성공과 구분한다. 확인 전 재시도에는 동일 선택 식별자와 동일 카드 결과를 사용한다.

## 실패 및 예외

- “네가 골라줘”: 직접 선택하도록 안내한다. 대리 추첨하지 않는다.
- 전달 실패: 선택 카드를 유지하고 전달 재시도 버튼을 제공한다.
- 카드 확정 전 질문 변경: 선택을 비활성화하고 수정 요청을 발행한다. 새 확정 질문을 받으면 같은 덱으로 선택을 재개한다.
- 세션 종료 신호를 받으면 선택을 비활성화하고 미완료 전달을 취소한다. 연결 해제는 수행하지 않는다.
- 카드 자산을 표시할 수 없으면 선택을 비활성화하고 오류를 안내한다.

## 완료 조건

아래 항목을 모두 통과하면 F03 구현 완료로 판정한다.

- [ ] AC01: 확정 질문이 없을 때 선택 불가, 수신 후 선택 안내와 카드 UI가 제공된다.
- [ ] AC02: 78장의 뒷면 카드에서 3장을 터치 또는 음성으로 고른다.
- [ ] AC03: 탐색, 재렌더링, 화면 크기 변경에도 위치별 카드 정체가 유지된다.
- [ ] AC04: 연속 터치에도 3장만 확정되고 나머지 선택이 잠긴다. 중복·범위 밖 음성 번호는 다시 묻는다.
- [ ] AC05: 공개 카드와 수신부가 받은 카드 ID 및 방향이 일치한다.
- [ ] AC06: 전달 실패 후 재시도해도 같은 선택 식별자와 카드가 전달된다.
- [ ] AC07: 카드 확정 전 질문 수정 시 선택을 잠그고, 새 질문 확정 후 같은 덱으로 재개한다.
- [ ] AC08: 대리 선택 요청에 자동 추첨하지 않으며 종료 신호 후 추가 선택/전달이 없다.

## 독립 검증 방법

확정 질문을 테스트 입력으로 제공하고, AI 대신 카드 결과의 수신 성공/실패를 반환하는 테스트 수신부를 연결한다. 선택 안내는 생성된 안내 문장으로 확인한다. 실제 음성 연결이나 카드 해석 없이 UI, 선택 결과, 재시도를 검증한다.

## 제외 범위

AI 대리 선택, 재추첨, 3장 외 스프레드, 생성형 카드 이미지, 선택 방식 비교 실험.
