# F04 - 카드 해석 및 후속 대화

> 상태: 팀 검토용 초안. 구현 범위와 완료 조건을 검토하기 위한 문서입니다.

## 목적

확정된 카드와 상담 질문을 연결한 해석을 제공하고 후속 질문에 답한다.

## 책임 범위

- 소유: 카드 의미 참조, 첫 해석 생성, 후속 질문 응답, 질문 및 카드 맥락 유지, 응답 길이 조정.
- 경계: 카드 선택과 결과 전달 재시도는 F03, 상담 질문 확정은 F02, 음성 재생/끼어들기/종료 의사 처리는 F01이 담당한다.
- 응답 내용의 정확성과 일관성을 판정하며 마이크, 재생 중단, 연결 해제 여부는 이 기능의 완료 기준이 아니다.

## 기본 흐름

1. 유효한 상담 질문과 카드 결과를 받는다.
2. 별도 사용자 명령 없이 1번 자리부터 한 장씩 앞면을 공개하고 해석한다.
3. 장마다 카드 의미(정/역방향) → 자리 의미와 고민 연결 → 생각해 볼 점을 말하고, 사용자 반응을 듣는다. 두 번째 장부터는 앞 카드와 연결한다.
4. 3장이 끝나면 종합하고 "퀸의 한마디"를 한 문장으로 준다.
5. 사용자의 후속 질문과 길이 조정 요청에 답한다.
6. 세션 종료 신호를 받으면 응답 생성을 중지한다.

## 동작 규칙

- 첫 해석은 카드 의미 → 고민과 연결 → 생각해 볼 점으로 구성한다.
- 한 번에 2~3문장씩 말하고 사용자에게 말을 넘긴다. 카드 한 장당 약 1분, 3장 해석과 종합까지 약 5분을 목표로 한다. 실제 재생 성능은 이 기능의 판정 대상이 아니다.
- 톤: 상황과 상대방은 냉정하게 짚고 사용자는 지지한다. 팩폭 뒤에는 지지로 마무리한다(feature-list 페르소나).
- 미래, 합격, 관계 결과, 타인의 감정을 확정하지 않고 가능성과 관점으로 설명한다.
- 의료·법률·투자 등 전문 판단을 대신하지 않는다.
- 후속 대화에서 확정 질문과 같은 카드를 유지한다.
- “더 짧게”, “자세히 설명해줘” 및 정정 발화를 응답 내용에 반영한다.
- 동일 선택 식별자의 카드 결과가 재전달돼도 첫 해석을 중복 생성하지 않는다.
- 음성 종료 요청은 세션 제어부가 우선 처리한다. 이 기능에서 종료 인사를 생성하거나 연결을 닫지 않는다.

## 대화 예시

고정 대본이 아닌 내용 예시다.

- 입력: 확정 상담 질문과 카드 한 장.
- 타로 리더: “고르신 카드는 [확정 카드 이름]이에요.”라고 시작하고 카드 의미와 질문을 연결한다.
- 사용자: “그럼 지금 당장 결정하라는 뜻이야?”
- 타로 리더: 카드가 결정을 대신하지 않음을 설명하고 같은 질문과 카드에 기반한 관점을 제안한다.
- 금지: 다른 카드로 바꾸기, 사용자가 말하지 않은 사정을 사실로 추가하기.

## 입력과 결과

- 입력: 확정 상담 질문, 선택 식별자와 카드 ID/이름/방향, 카드 의미 자료, 세션 내 대화 맥락, 후속 사용자 발화.
- 결과: 첫 해석 및 후속 답변 내용, 입력 누락/불일치 오류, 응답 생성 실패 안내.
- 생성된 응답은 음성 처리부에 전달한다. 이 문서에서는 특정 모델이나 내부 출력 형식을 지정하지 않는다.
- 카드 결과 수신 확인과 해석 생성 성공을 분리하여, 생성 실패가 재추첨을 일으키지 않게 한다.

## 실패 및 예외

- 질문/카드 누락 또는 카드 ID와 이름 불일치: 해석하지 않고 입력 오류를 반환한다. 대체 카드를 만들지 않는다.
- 해석 생성 실패: 실패를 알리고 같은 질문/카드로 다시 요청할 수 있게 한다. 재시도는 중복 수신과 구분되는 명시적 요청으로 처리한다.
- 추가 카드 요청: 3장 기준임을 안내한다. 직접 카드 선택이나 재추첨을 실행하지 않는다.
- 세션 종료 신호 후 생성 결과는 응답 전달 대상으로 내보내지 않는다.

## 완료 조건

아래 항목을 모두 통과하면 F04 구현 완료로 판정한다.

- [ ] AC01: 유효한 질문과 카드 수신 후 추가 사용자 요청 없이 첫 해석을 생성한다.
- [ ] AC02: 입력 카드의 이름과 의미를 정확히 사용하고 확정 질문과 연결한다.
- [ ] AC03: 카드 의미, 고민과 연결, 생각해 볼 점이 첫 응답에 포함된다.
- [ ] AC04: 후속 질문에서도 같은 카드와 맥락을 유지하고 없는 사실을 추가하지 않는다.
- [ ] AC05: 짧게/자세히/정정 요청을 응답 내용에 반영한다.
- [ ] AC06: 동일 선택 결과 재수신 시 첫 해석이 중복 생성되지 않는다.
- [ ] AC07: 입력 누락/불일치에는 해석하지 않고 오류를 반환한다.
- [ ] AC08: 생성 실패 후 명시적 재시도는 같은 질문과 카드로 수행된다.
- [ ] AC09: 추가 카드 요청으로 새 카드를 만들지 않으며 종료 신호 후 응답 전달이 없다.

## 독립 검증 방법

테스트용 확정 질문, 카드 의미 자료, 선택 결과 및 후속 발화를 직접 입력한다. 생성 응답은 텍스트로 확인하고 카드 이름/의미/질문 연결을 기준 자료와 비교한다. 카드 UI나 마이크 없이 중복 결과, 잘못된 입력, 생성 실패와 재시도를 검증한다.
