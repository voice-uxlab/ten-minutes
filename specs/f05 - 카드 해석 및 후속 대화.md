# F05 - 카드 해석 및 후속 대화

> 상태: 팀 검토용 초안. 이 대화에서 작성한 MVP 제안이며, 이 파일의 커밋만으로 팀의 구현 준비 완료나 PRD.md의 미정 항목 확정을 의미하지 않습니다.
>
> 마일스톤: [최소 사용자 흐름](feature-list.md). 흐름: 이용 안내 확인 → 음성 대화 시작 → 고민 구체화 → 터치로 카드 선택 → 카드 해석 → 후속 대화 → 종료.

## 목적

선택한 카드를 사용자의 고민에 연결해 설명하고 사용자가 자신의 상황을 돌아보도록 돕는다.

## 시작 조건 및 의존성

F01 세션이 연결되어 있고 F03의 확정 질문과 F04의 선택 카드가 존재한다. 카드 의미를 참조할 자료가 필요하다.

## 기본 흐름

1. 선택 카드 이름을 안내한다.
2. 카드의 상징을 짧게 설명한다.
3. 상담 질문에 연결해 해석한다.
4. 생각해 볼 관점이나 행동을 제안한다.
5. 사용자 후속 질문에 응답한다.
6. 사용자가 마치겠다고 하면 짧게 인사하고 F01 세션을 종료한다.

## 동작 규칙

- 첫 해석은 카드 의미 → 고민과 연결 → 생각해 볼 점으로 구성한다.
- 첫 해석 길이의 초기 목표는 약 30–60초이며 구현 후 실제 발화로 확인한다.
- 결과를 단정하지 않고 가능성과 관점으로 제시한다.
- 후속 대화는 같은 질문과 카드를 유지한다.
- “더 짧게”, “자세히 설명해줘” 등의 요청을 반영한다.
- 사용자가 끼어들면 F01이 기존 재생을 중단하고 추가 발화를 반영한다.
- “오늘은 여기까지 할게” 등 명확한 종료 의사는 짧은 인사 후 종료한다.
- “고마워”처럼 종료 여부가 모호하면 마칠지 확인한다.
- 화면 종료 버튼은 즉시 종료한다. 음성 인사를 끝까지 기다리도록 강제하지 않는다.
- 미래, 합격, 관계 결과, 타인의 감정을 확정하거나 전문 자문을 대신하지 않는다.

## 대화 예시

고정 대본이 아닌 행동 예시다.

- 이전 상태: 질문과 카드 한 장이 확정됨.
- 타로 리더: “고르신 카드는 [확정된 카드 이름]이에요.”라고 시작해 의미와 질문을 연결한다.
- 사용자: “그럼 지금 당장 결정하라는 뜻이야?”
- 타로 리더: 카드가 결정을 대신하지 않음을 설명하고, 기존 질문과 카드에 근거한 살펴볼 관점을 제안한다.
- 금지: 다른 카드로 바꾸어 말하기, 사용자가 말하지 않은 사정을 사실로 추가하기.

## 입력과 결과

- 입력: 확정 질문, 선택 카드 ID와 의미, 현재 세션의 대화 맥락, 사용자 후속 질문.
- 결과: 카드 해석과 후속 음성 응답.
- 종료 조건: 사용자 종료 의사/버튼, 화면 이탈, 복구 불가능한 연결 오류.

## 실패 및 예외

- 카드 정보가 없으면 임의의 카드로 해석하지 않고 F04 결과 전달 복구를 안내한다.
- 추가 카드 요청은 한 장 기준임을 안내하고 새 상담 시작 방법을 설명한다. 자동 재추첨하지 않는다.
- 사용자 사정이나 타인의 감정을 만들어내지 않는다.
- 연결 오류는 F01 기준으로 처리하며 오류 전후 다른 카드로 바꾸지 않는다.

## 완료 조건

- [ ] 화면 카드와 동일한 이름 및 의미를 설명한다.
- [ ] 해석을 확정된 상담 질문에 연결한다.
- [ ] 후속 질문에서도 같은 카드와 맥락을 유지한다.
- [ ] 답변 길이 조정과 끼어들기를 반영한다.
- [ ] 모호한 종료 표현은 확인하고 명확한 종료 표현은 처리한다.
- [ ] 음성 인사 후 종료하며 종료 이후 추가 응답은 재생하지 않는다.
- [ ] 카드 정보가 없을 때 해석을 만들어내지 않는다.

## 관련 기능 및 결정

- 선행: F01, F03, F04.
- PRD.md 관련 결정: P03, P05, D03, T04–T05, V02, V05, V07.
- 미결정: 카드 의미 자료, 해석 품질 검토 담당, 말투 및 민감 상황 응답 원칙은 구현 전에 확정한다.

## 공통 요구사항

- 한 세션에서 질문 하나와 카드 한 장을 다룬다.
- 상담 질문, 선택 카드, 진행 단계는 앱이 관리한다. AI 발화만으로 카드 선택이나 단계 완료를 확정하지 않는다.
- 앱 DB에 음성, 대화 원문, 상담 결과를 영구 저장하지 않는다. 종료 시 세션의 대화 및 카드 상태를 초기화한다.
- 시작 전에 AI 음성, 오락 및 자기 성찰 목적, 외부 API 전송과 데이터 처리 방식을 안내한다.
- 지원 목표는 iPhone Safari와 데스크톱 Chrome이며 실제 기기에서 전체 흐름을 검증한다.
- 로그인, 앨범, 이미지 생성, 자막, 관리자 분석, 연구 데이터 수집과 파라미터 실험은 이번 범위에서 제외한다.
