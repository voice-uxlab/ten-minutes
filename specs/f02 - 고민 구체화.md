# F02 - 고민 구체화

> 상태: 팀 검토용 초안. 이 대화에서 작성한 MVP 제안이며, 이 파일의 커밋만으로 팀의 구현 준비 완료나 PRD.md의 미정 항목 확정을 의미하지 않습니다.
>
> 마일스톤: [최소 사용자 흐름](feature-list.md). 흐름: 이용 안내 확인 → 음성 대화 시작 → 고민 구체화 → 터치로 카드 선택 → 카드 해석 → 후속 대화 → 종료.

## 목적

사용자의 자유로운 이야기를 카드 해석에 사용할 상담 질문 하나로 정리한다.

## 시작 조건 및 의존성

F01의 음성 세션이 연결되어 있고 아직 카드가 선택되지 않았다.

## 기본 흐름

1. 타로 리더가 고민을 듣는다.
2. 필요한 경우 추가 질문을 한다.
3. 상담 질문을 한 문장으로 정리해 말하고 화면에도 표시한다.
4. 사용자가 확인하면 질문을 확정한다.
5. “화면에서 마음이 가는 카드 한 장을 골라주세요”라고 안내하고 F03를 활성화한다.

## 대화 예시

고정 대본이 아닌 동작과 말투 예시다.

- 사용자: “요즘 회사에서 고민이 많아요.”
- 타로 리더: “어떤 부분이 가장 마음에 걸리세요?”
- 사용자: “다른 팀으로 옮길지 고민이에요.”
- 타로 리더: “‘팀 이동을 앞두고 어떤 점을 살펴보면 좋을까?’라는 질문으로 카드를 만나볼까요?”
- 사용자: “네.”
- 시스템: 상담 질문 확정 및 카드 선택 활성화.

## 동작 규칙

- 질문이 명확하면 추가 질문을 생략할 수 있다.
- 추가 질문은 한 번에 하나씩, 원칙적으로 2회 이내로 한다. 정보가 부족하면 넓은 질문으로 정리한다.
- 사용자는 음성으로 질문을 수정할 수 있으며 수정 후 다시 확인한다.
- “그냥 뽑고 싶어요”라고 하면 자세한 사정을 요구하지 않고 일반적인 자기 성찰 질문을 제안한다.
- 사용자 확인 전에는 질문을 확정하거나 카드 선택을 활성화하지 않는다.
- 여러 고민이 나오면 이번 상담에서 다룰 하나를 고르도록 돕는다.
- F03에서 카드가 확정되기 전 질문 변경을 요청하면 이 단계로 돌아올 수 있다.
- 의료·법률·투자 판단이나 위기 대응을 타로로 대신하지 않고 서비스 한계를 안내한다.

## 입력과 결과

- 입력: 사용자 고민과 수정 요청, 질문 확인 응답.
- 결과: 확정된 상담 질문 한 문장과 카드 선택 가능 상태.
- 종료 조건: 사용자 확인 및 F03로 전환, 또는 F01의 세션 종료.

## 실패 및 예외

발화를 알아듣지 못했거나 확인 응답이 모호하면 추측하여 확정하지 않고 다시 묻는다. 사용자가 말하지 않은 개인 사정을 질문에 추가하지 않는다.

## 완료 조건

- [ ] 자유로운 고민을 상담 질문 한 문장으로 정리한다.
- [ ] 화면의 질문과 음성으로 확인한 질문이 일치한다.
- [ ] 수정 요청을 반영하고 다시 확인받는다.
- [ ] 자세한 고민을 말하지 않아도 진행할 수 있다.
- [ ] 확인 전에는 카드 선택이 비활성화되고 확인 후 활성화된다.
- [ ] 여러 고민 중 하나를 선택해 진행한다.
- [ ] 잘못 들은 내용을 임의로 확정하지 않는다.

## 관련 기능 및 결정

- 선행: F01. 후행: F03, F04.
- PRD.md 관련 결정: P03, P05, D03, T05, V05, V07.
- 미결정: 공통 말투와 위기 상황 안내 문구는 구현 전 팀 검토가 필요하다.

## 공통 요구사항

- 한 세션에서 질문 하나와 카드 한 장을 다룬다.
- 상담 질문, 선택 카드, 진행 단계는 앱이 관리한다. AI 발화만으로 카드 선택이나 단계 완료를 확정하지 않는다.
- 앱 DB에 음성, 대화 원문, 상담 결과를 영구 저장하지 않는다. 종료 시 세션의 대화 및 카드 상태를 초기화한다.
- 시작 전에 AI 음성, 오락 및 자기 성찰 목적, 외부 API 전송과 데이터 처리 방식을 안내한다.
- 지원 목표는 iPhone Safari와 데스크톱 Chrome이며 실제 기기에서 전체 흐름을 검증한다.
- 로그인, 앨범, 이미지 생성, 자막, 관리자 분석, 연구 데이터 수집과 파라미터 실험은 이번 범위에서 제외한다.
