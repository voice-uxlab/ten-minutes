# F01 - 음성 대화 세션

> 상태: 팀 검토용 초안. 구현 범위와 완료 조건을 검토하기 위한 문서입니다.

## 목적

음성 연결, 송수신, 마이크 조작, 끼어들기 및 종료를 제공한다. 상담 내용과 카드 처리의 정확성은 이 기능의 구현 판정에 포함하지 않는다.

## 책임 범위

- 소유: 마이크 권한, 세션 연결 상태, 음성 송수신, 재생 제어, 마이크 켜기/끄기, 종료 의사 처리, 연결 오류.
- 경계: 타로 인사와 고민 질문은 F02, 카드 선택 안내는 F03, 카드 해석 내용은 F04가 담당한다.
- 다른 기능에서 생성한 응답 내용은 음성으로 전달하지만 그 내용을 생성하거나 검증하는 책임은 갖지 않는다.

## 기본 흐름

1. 사용자가 ‘대화 시작’을 누른다.
2. 마이크 권한을 요청하고 허용되면 세션을 연결한다.
3. 연결 상태를 표시하고 음성을 주고받는다.
4. 사용자 요청에 따라 마이크 입력이나 AI 재생을 제어한다.
5. 종료 버튼, 명확한 음성 종료 요청, 화면 이탈 시 세션을 정리한다.

## 화면 및 동작 규칙

| 항목 | 요구사항 |
|---|---|
| 상태 표시 | 대기, 연결 중, 대화 중, 연결 오류 및 사용자 발화 대기/응답 준비/AI 발화 상태를 구분한다. |
| 중복 연결 | 연결 중 또는 대화 중 시작 버튼을 반복 조작해도 세션 하나만 생성한다. |
| 끼어들기 | 사용자 발화 감지 시 기존 재생을 중단하고 해당 응답의 대기 음성을 버린다. 새 발화를 대화 처리부로 전달한다. |
| 마이크 | 끄면 입력을 중단하고 꺼진 상태를 표시한다. 다시 켜면 입력을 재개한다. |
| 버튼 종료 | 즉시 연결, 마이크, 재생 중 및 대기 음성을 정리한다. |
| 음성 종료 | “오늘은 여기까지 할게” 등 명확한 종료 의사는 짧은 인사 재생 후 정리한다. “고마워”처럼 모호하면 종료 여부를 확인한다. |
| 종료 우선순위 | 음성 종료 인사 중에도 종료 버튼은 즉시 정리한다. 종료 요청은 일반 상담 응답보다 먼저 처리한다. |
| 재시작 | 종료 후 새 세션으로 시작하며 이전 세션의 지연 응답을 재생하지 않는다. |
| 화면 이탈 | 상담 화면을 벗어나면 연결과 마이크 및 재생을 정리한다. |

## 입력과 결과

- 입력: 시작/종료/마이크 조작, 사용자 음성, 응답 음성, 권한 및 네트워크 상태.
- 결과: 연결 상태, 입력 음성 전달, 응답 재생, 종료된 세션.
- 상담 단계와 관계없이 종료 의사는 여기에서 처리한다. 다른 기능이 종료 발화를 해석하거나 연결을 닫지 않는다.

## 실패 및 예외

- 마이크 거부/사용 불가: 이유와 권한 설정 방법 및 재시도를 표시한다.
- 연결 실패: 연결 중 상태를 해제하고 재시도 버튼을 제공한다.
- 통화 중 연결 끊김: 재생을 멈추고 오류 및 새 상담 시작 방법을 안내한다.
- 종료 이후 도착한 응답은 폐기한다.
- API 키는 클라이언트 코드나 저장소에 포함하지 않는다.

## 완료 조건

아래 항목을 모두 통과하면 F01 구현 완료로 판정한다.

- [ ] AC01: 타로 로직 없이 일반 응답으로 음성 대화 3회를 주고받는다.
- [ ] AC02: 시작 연속 클릭에도 활성 세션은 하나다.
- [ ] AC03: AI 발화 중 끼어들면 기존 음성과 대기 음성이 중단되고 새 발화가 전달된다.
- [ ] AC04: 마이크 끄기 후 입력이 중단되고 다시 켜면 재개된다.
- [ ] AC05: 종료 버튼 및 화면 이탈 후 마이크, 연결, 재생이 모두 정리된다.
- [ ] AC06: 명확한 음성 종료 요청은 인사 후 종료되고 모호한 표현은 확인한다.
- [ ] AC07: 종료 인사 중 버튼 종료가 가능하고 새 세션에 이전 음성이 섞이지 않는다.
- [ ] AC08: 권한 거부, 최초 연결 실패, 연결 중 끊김 각각에서 안내와 재시작 경로를 확인한다.

## 독립 검증 방법

상담 및 카드 처리부 대신 짧은 일반 응답을 반환하는 테스트 대상을 연결한다. 카드 화면이나 타로 해석 없이 위 완료 조건을 검증한다. 검증 브라우저는 iPhone Safari와 데스크톱 Chrome이다.
