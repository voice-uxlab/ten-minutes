# F01 - 음성 대화 세션

> 상태: 팀 검토용 초안. 이 대화에서 작성한 MVP 제안이며, 이 파일의 커밋만으로 팀의 구현 준비 완료나 PRD.md의 미정 항목 확정을 의미하지 않습니다.
>
> 마일스톤: [최소 사용자 흐름](feature-list.md). 흐름: 이용 안내 확인 → 음성 대화 시작 → 고민 구체화 → 터치로 카드 선택 → 카드 해석 → 후속 대화 → 종료.

## 목적

사용자가 복잡한 설정 없이 타로 리더와 연결해 안정적으로 음성 대화하고 종료한다.

## 시작 조건 및 의존성

이용 안내와 필요한 데이터 처리 고지를 확인한 사용자가 상담 화면에 접속한다. API 제공업체, 모델, 목소리, 개발 스택은 PRD.md의 관련 결정에 따라 확정하며 이 문서에서 지정하지 않는다.

## 기본 흐름

1. 사용자가 ‘대화 시작’을 누른다.
2. 마이크 권한을 요청하고 허용되면 세션을 연결한다.
3. 연결 완료 후 타로 리더가 인사하고 고민을 묻는다.
4. 사용자와 타로 리더가 음성으로 대화한다.
5. 종료 버튼 또는 F04의 명확한 음성 종료 의사에 따라 세션을 종료한다.

## 화면 및 동작 규칙

| 항목 | 요구사항 |
|---|---|
| 연결 상태 | 대기, 연결 중, 대화 중, 연결 오류를 표시한다. |
| 대화 상태 | 사용자 발화 대기, 응답 준비 중, AI 발화 중을 구분한다. |
| 중복 연결 | 연결 중이나 대화 중에는 새 세션을 생성하지 않는다. |
| 끼어들기 | AI 발화 중 사용자가 말하면 기존 재생을 중단하고 추가 발화를 처리한다. 이전 응답의 대기 음성이 다시 재생되지 않아야 한다. |
| 마이크 제어 | 켜기/끄기 버튼을 제공하고 꺼진 상태에서는 입력을 중단한다. |
| 종료 | 세션 연결, 마이크 사용, 재생 중 및 재생 대기 음성을 정리한다. |
| 재시작 | 종료 후 시작하면 새로운 상담으로 시작한다. |
| 화면 이탈 | 상담 화면을 벗어나면 마이크와 연결을 정리한다. |

같은 상담 화면에 연결 상태, 대화 시작/종료, 마이크 제어, 상담 질문 및 카드 영역을 배치한다.

## 입력과 결과

- 입력: 시작/종료/마이크 조작, 사용자 음성, 마이크 권한 상태.
- 결과: 연결 및 대화 상태, AI 음성, 종료된 세션.
- 종료 조건: 사용자의 종료 요청, 화면 이탈 또는 복구 불가능한 연결 오류.

## 실패 및 예외

- 마이크 거부/사용 불가: 원인과 권한 설정 방법을 안내하고 재시도할 수 있게 한다.
- 연결 실패: 연결 중 상태를 해제하고 재시도 버튼을 제공한다.
- 통화 중 연결 끊김: 재생을 멈추고 오류를 알린다. 상담을 이어 복구할 수 없다면 새 상담 시작을 안내한다.
- 종료 직전 도착한 응답은 종료 후 재생하지 않는다.
- API 키는 클라이언트 코드나 저장소에 포함하지 않는다.

## 완료 조건

- [ ] 시작부터 종료까지 3회 이상 음성 대화를 주고받는다.
- [ ] 시작 버튼 연속 클릭 시 세션은 하나만 생성된다.
- [ ] 끼어들기 후 기존 응답이 겹치거나 다시 재생되지 않는다.
- [ ] 마이크 끄기 시 입력이 중단된다.
- [ ] 종료 및 화면 이탈 후 마이크와 재생이 중단된다.
- [ ] 종료 후 새 상담을 시작할 수 있다.
- [ ] 권한 거부와 연결 실패 시 복구 방법이 표시된다.
- [ ] 지원 대상 두 브라우저에서 위 항목을 확인한다.

## 관련 기능 및 결정

- F02 고민 구체화, F03 사용자 주도 카드 선택, F04 카드 해석 및 후속 대화.
- PRD.md 관련 결정: V01–V07, E01, E03–E06.
- 미결정: 제공업체/모델/목소리, 연결 대기 및 무응답 시간 한도, 세션 사용량 한도. 구현 전에 확정한다.

## 공통 요구사항

- 한 세션에서 질문 하나와 카드 한 장을 다룬다.
- 상담 질문, 선택 카드, 진행 단계는 앱이 관리한다. AI 발화만으로 카드 선택이나 단계 완료를 확정하지 않는다.
- 앱 DB에 음성, 대화 원문, 상담 결과를 영구 저장하지 않는다. 종료 시 세션의 대화 및 카드 상태를 초기화한다.
- 시작 전에 AI 음성, 오락 및 자기 성찰 목적, 외부 API 전송과 데이터 처리 방식을 안내한다.
- 지원 목표는 iPhone Safari와 데스크톱 Chrome이며 실제 기기에서 전체 흐름을 검증한다.
- 로그인, 앨범, 이미지 생성, 자막, 관리자 분석, 연구 데이터 수집과 파라미터 실험은 이번 범위에서 제외한다.
