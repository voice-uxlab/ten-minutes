# Voice UX Lab — 프로젝트 아이디어 제출

Voice UX Lab 팀원들의 프로젝트 아이디어를 모으는 저장소입니다.

## 제출 방법

1. 저장소 루트에 `{project-name}.md` 형식으로 Markdown 파일을 생성합니다.
   - 예: `hands-free-work-log.md`
   - 파일명은 프로젝트를 알아볼 수 있는 영문 소문자와 하이픈으로 작성합니다.
2. [TEMPLATE.md](TEMPLATE.md)를 복사하고, 제안자와 프로젝트명을 입력한 뒤 모든 문항의 답변을 직접 작성합니다.
   - 아직 확인하지 못한 내용은 가정과 추가로 확인할 내용을 구분해 적습니다.
   - 해당하지 않는 문항은 그 이유를 적습니다.
3. 작성한 파일을 `main` 브랜치에 직접 커밋하여 업로드합니다. (수정필요)
   - Pull Request(PR)는 생성하지 않습니다. (수정필요)
   - 다른 팀원의 제출 파일을 덮어쓰지 않도록 파일명 중복을 확인합니다.

## 개발 환경

현재 저장소는 프로젝트 아이디어와 기술 문서를 관리하는 단계입니다. 애플리케이션 실행 환경이 구성되면 각 애플리케이션의 README에 필요한 런타임, 패키지 매니저, 설치 명령을 추가합니다.

- 인증 정보와 API 키는 환경 변수로 관리합니다.
- 개인용 `.env` 파일은 커밋하지 않습니다.
- 의존성은 프로젝트에서 지정한 패키지 매니저로 설치합니다.

## 실행 방법

현재 실행 가능한 애플리케이션 명령은 정의되어 있지 않습니다. 웹 또는 백엔드 애플리케이션이 추가되면 다음 항목을 이 문서와 각 영역의 README에 기록합니다.

```text
설치: <의존성 설치 명령>
실행: <개발 서버 실행 명령>
검증: <lint / test / build 명령>
```
