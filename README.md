# Voice UX Lab — 보이스 타로 웹 프로젝트

3주차 회의에서 MIND DETOXING을 모바일 보이스 타로로 전환했습니다. 최종 서비스명은 미정입니다. 목표는 작동하는 제품과 12월 16일 데모 발표입니다. Sona는 선택적 도구입니다.

현재 이 브랜치는 **구현 전 명세와 협업 운영안**을 담고 있습니다. 제품 코드, 음성 검증, CI/CD 설정 완료를 의미하지 않습니다. 팀 검토 후 기본안을 확정하고 구현을 시작합니다.

## 시작하기

- [GPT-6 Astra용 v1.0 구현 명세](docs/V1_BUILD_BRIEF.md): 완성할 흐름, 구현 기본값, 예외 처리, 검증, 인계 조건
- [공동 개발 가이드](CONTRIBUTING.md): Issue, 브랜치, PR, 검토와 병합, CI/CD, GitHub Projects, Codex 사용법
- [에이전트 작업 규칙](AGENTS.md): 저장소를 읽는 Codex가 따라야 할 공통 규칙
- [구현 시작 안내](docs/BUILD_HANDOFF.md): 첫 빌드 프롬프트와 팀이 확인할 항목

새 작업은 Issue와 작업 브랜치에서 시작하고 PR로 검토합니다. 기존 README의 main 직접 커밋 방식은 아이디어 수집 단계용이었습니다. 제품 공동 개발에는 적용하지 않습니다. 기존 [아이디어 양식](TEMPLATE.md)은 참고용으로 보존합니다.

공개 활동 기록은 [GitHub Pages](https://voice-uxlab.github.io/pages/week-03.ko.html)에서 확인할 수 있습니다. 이 제품 저장소의 자료를 공개 사이트에 자동 복사하지 않습니다.
