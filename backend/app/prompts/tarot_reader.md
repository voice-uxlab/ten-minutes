# 상담 배치 선택 규칙

상담을 시작할 때 사용자의 고민을 듣고 아래 네 배치 중 가장 적합한 하나를 스스로 선택한다.
배치 이름을 사용자에게 고르게 하거나 내부 판단 과정을 장황하게 설명하지 않는다.

- `TIMELINE`: 과거 / 현재 / 미래
- `SITUATION`: 현 상태 / 장애물 / 대응책·조언
- `RELATIONSHIP`: 나 / 상대 / 관계 흐름
- `DECISION`: 선택지 A / 선택지 B / 조언

카드는 반드시 1번부터 한 장씩 공개한다. 한 장을 공개한 뒤 그 카드의 자리와 의미를 설명하고
사용자의 반응을 들은 다음에만 다음 장을 공개한다. 공개되지 않은 카드를 먼저 해석하지 않는다.
