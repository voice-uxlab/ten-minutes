# 퀸의 타로 — 레나와의 전화 상담 (요구사항)

날짜: 2026-11-05 · 목표: 11월 말 심사 제출 (모바일 웹)

## 무엇을 만드나
2030 여성 유저("공주")가 퀸 타로 리더 **레나**에게 전화를 걸어 연애·고민 사연을 털어놓고, 카드 3장으로 리딩을 받는다. 상담이 끝나면 **위로받았고, 정신이 번쩍 들었고, 더 듣고 싶은** 상태가 되어야 한다.

## 레나의 톤
- 상황과 상대방에게는 냉정하게, 사용자는 무조건 퀸 대접한다.
- 팩폭 다음에는 반드시 지지로 마무리한다. 사용자를 깎아내리지 않는다. 상대를 비난하지 않고 판단만 말한다.
- 한 번에 2~3문장. 카드 한 장 해석이 끝날 때마다 사용자에게 말을 돌려준다.

## 통화 흐름
1. 사연 듣기와 공감 → 질문을 한 줄로 정리
2. 질문에 맞게 자리 3개를 정한다 (예: 나 / 그 사람 / 관계의 흐름)
3. 78장 카드를 펼친다 → 사용자는 번호를 **말하거나 탭해서** 3장을 고른다. 셔플과 역방향은 서버가 무작위로 정한다.
4. 한 장씩 뒤집으며 해석 (역방향 포함, 카드끼리 연결)
5. 종합 → 퀸의 한마디 → 사용자 질문

## 과금
- **10분 이용권**. 남은 시간은 버린다.
- 1분 남았을 때 레나가 마무리를 시작한다. 이용권이 있으면 연장할지 묻고, 사용자가 말이나 탭으로 고른다. 대화 도중에 끊기지 않게 한다.
- **가입 후 첫 통화 5분 무료**: 카드 장수는 막지 않고 시간만 제한한다. 이용권 안내는 마지막 1분에만 한다. 5분 안에 못 본 카드는 잠긴 채로 남긴다 → 이용권으로 이어서 보거나, 결제 후 "다시 전화"로 같은 카드를 이어서 본다.

## 리포트
- 나만 보는 화면: 카드 3장, 질문, 요약, 자리별 해석, 퀸의 한마디
- 공유 카드: 사연을 뺀 카드 3장과 퀸의 한마디만 담은 세로 이미지 (스토리 크기)

## 연출
- 통화 화면 상단에 레나 목소리에 반응하는 이펙트, 하단에 음소거와 종료 버튼
- 효과음: 연결음, 셔플, 카드 고르기, 카드 뒤집기 / 배경음은 낮게 깔고 켜고 끌 수 있다

## 이번 범위에서 빼는 것 (심사용 데모)
- 소셜 로그인 → 닉네임만 받는다 (카카오는 나중에)
- 실제 결제 → "이용권 구매(데모)" 버튼
- 카드 일러스트 → 글자로 된 카드 (라이더 웨이트 이미지는 저작권을 확인한 뒤 교체)
- 다른 페르소나, 조언 카드 추가 판매

## 안전과 고지
