검토 기준과 남은 외부 설정

22개 자동 테스트 통과 · 20개 사용자 화면 표시 및 실제 앱 전환 검증.
전체 화면의 픽셀 단위 시각 검토, 소셜 실계정 로그인, 음성 지연 실측은 완료 전이에요. “내 확인”은 직접 검토한 페이지를 표시하는 체크예요.

  • 스택: 기존 레포의 Node.js + 순수 HTML/CSS/JavaScript + WebSocket. React나 별도 프레임워크로 전환하지 않았어요.
  • 음성: OpenAI Realtime 입력·답변 텍스트 → 기존 타입캐스트 스트리밍 출력. 기본 말하기 속도 1.2배.
  • 카드: 미리보기는 시안의 별·태양·절제 예시예요. 실제 상담·시범 통화는 78장 셔플 결과를 사용해요. 아직 고르지 않은 카드 뒷면은 표시하지 않아요.
  • 에셋: Figma 원본 노드에서 3x PNG로 export했어요. 별·태양·절제 외 75종의 전용 일러스트는 이 시안에서 확보되지 않아 공통 심볼과 실제 카드 이름으로 표시해요.
  • 시간: 미리보기는 시안의 10분 예시, 실제 상담은 기존 무료 5분·이용권 10분 규칙이에요.
  • 녹음: 동의한 경우 마이크 음성을 기기 안에서 녹음해 종료 후 저장해요. AI 음성은 포함되지 않고 서버에 업로드하지 않아요.
  • 소셜 로그인: OAuth 연동 코드와 세션 처리는 구현했어요. 제공업체 키·복귀 주소 등록 후 실제 계정으로 검증해야 해요. 아래 설정 상태를 확인해 주세요.
  • 20번: 팀 리뷰 메모이며 사용자 앱에는 별도 페이지로 노출하지 않아요. 21번 리포트는 기존 PoC 기능을 유지한 추가 화면이에요.
